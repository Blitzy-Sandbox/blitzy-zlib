Section 01

Why migrate to Rust

Removing a class of memory-safety defects without touching the wire format or the public contract.

The Case for the Rewrite

Memory safety without disruption

Defects eliminated Use-after-free and double-free are unrepresentable in the safe core — enforced by the borrow checker.
Maintainability Exhaustive enum + match replace fragile integer state and goto.
Drop-in compatibility Exported C symbols match exactly — existing callers relink with no code changes.
Contract preserved Same RFC formats, same API surface, same compressed bytes.

Behavior-preserving · same repository · zero C dependency in the shipped crate

Memory Model

Manual allocation becomes ownership

graph TD
  A["ZStream (owned by caller)"]
  A -->|Box| B["DeflateState"]
  A -->|Box| C["InflateState"]
  B -->|Vec u8| D["window"]
  B -->|Vec u8| E["pending_buf"]
  B -->|Box u16| F["head / prev"]
  C -->|Vec u8| G["window"]
  C -->|Box Code| H["codes"]
  A -.->|Drop| I["frees all — no zfree, no leak"]
  • Ownership tree replaces ZALLOC/ZFREE hooks.
  • Raw next_in/next_out pointers become &[u8] slices.
  • Drop replaces deflateEnd/inflateEnd — deterministic, leak-free.
Allocator trait preserves custom zalloc / zfree for C callers

Section 03

Risk & mitigation

Equivalence is proven, not assumed — and unsafe code is fenced into two audited sites.

Correctness & Assurance

Proving equivalence

Byte-for-byte oracle Interop tests will compare output to flate2 (canonical C zlib) byte-for-byte.
Unsafe confined By design, unsafe is confined to ffi.rs and inflate/fast.rs; every block carries a SAFETY note.
Official vectors Ports of example.c, infcover.c and minigzip will drive the test suite.

Planned layered validation · regression · coverage · property · round-trip · checksum

Target · 47 unsafe occurrences across 9 files · >98% safe by line

Performance Gates

Targets, measured against C zlib
